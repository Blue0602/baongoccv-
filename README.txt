# Nguyễn Thị Bảo Ngọc Portfolio Website

Cách dùng:
1. Giải nén file zip.
2. Upload file `index.html` lên GitHub repository.
3. Vào Settings → Pages → chọn branch `main` và thư mục `/root`.
4. Nếu muốn thêm CV, đặt file CV tên `cv.pdf` cùng cấp với `index.html`.
5. Nếu muốn thay ảnh chân dung, tìm đoạn `profile-photo` trong CSS và đổi link ảnh nền.

Website là dạng static 1 file, có thể chạy trực tiếp bằng GitHub Pages.
